# 指标定义（先定口径，再做看板）

> 适用数据：UCI Online Retail II，一家英国注册的线上礼品零售商 2009-12 至 2011-12 的全部交易，买家来自 40 多个国家，很多是批发商。
> 分析窗口：**2009-12-01 至 2011-11-30，共 24 个完整自然月**。货币：英镑（£）。

## 1. 这个看板要回答什么问题

看板的使用者设定为**跨境电商的经营负责人**，每周 / 每月看一次，要回答四个问题：

| 业务问题 | 对应指标 | 对应页面 |
|---|---|---|
| 生意整体好不好？ | GMV、净销售额、订单数、客单价、退货率 | ① 总览 |
| 变好还是变差，有没有季节性？ | 以上指标的月度趋势、同比 | ② 趋势 |
| 钱从哪来？哪个市场 / 品类在拉动或拖累？ | 国家贡献、品类贡献、国家 / 品类退货率 | ③ 国家与品类 |
| 客户留得住吗？ | 复购率、同期群留存、新客 90 天复购 | ④ 客户复购 |

每个指标都必须能落到上面某个问题上，答不上来的指标不放进看板。

## 2. 基础定义（所有指标共用）

| 概念 | 定义 |
|---|---|
| 销售订单 | 发票号（Invoice）**不以 C 开头**的发票，一张发票算一单 |
| 退货单 | 发票号**以 C 开头**的发票（原数据中 C = Cancellation，含取消和退货） |
| 商品行 | 商品编码以 5 位数字开头的行。邮费（POST、DOT、C2）、手工调整（M、ADJUST、B）、平台费（AMAZONFEE）、银行手续费、折扣、样品、礼品卡、测试商品**都不算商品** |
| 有效行 | 商品行 + 单价 > 0 + 去除完全重复行 |
| 时间 | 一律按**发票日期（InvoiceDate）**归属；退货按**退货单自己的日期**归属，不回溯到原订单 |
| 客户 | 有客户编号（Customer ID）的买家；**没有编号的订单计入 GMV 和订单数，但不计入客户数、复购和同期群** |
| 国家 | 发票上记录的买家国家 |

清洗每一步去掉了多少行、多少钱，见 [清洗日志](清洗日志.md)。

## 3. 指标口径

| 指标 | 公式 | 口径说明 | 为什么这样定 |
|---|---|---|---|
| **GMV（下单金额）** | Σ 销售订单有效行的 数量 × 单价 | 不扣退货、不含邮费 | 衡量"卖出去多少"，和平台常用 GMV 定义一致；邮费是代收的物流费，不是商品收入 |
| **退货额** | Σ 退货单有效行的 \|数量 × 单价\| | 按退货单日期归属 | 原数据没有"退货单 ↔ 原订单"的对应关系，只能按退货发生时间算；这会让退货和对应的销售可能落在不同月份，月度退货率会有波动 |
| **净销售额** | GMV − 退货额 | 同一时间段内相减 | 衡量"真正留下来的钱"，比 GMV 更接近收入 |
| **退货率（金额）** | 退货额 ÷ GMV | 同一时间段、同一筛选条件 | 用金额而不是单数：一张退 1 件和一张退 7 万件不应等权 |
| **退货单占比** | 退货单数 ÷ 销售订单数 | 辅助指标 | 看"有多少次不满意"，和金额退货率互相印证 |
| **订单数** | 销售订单的去重发票数 | 一张发票 = 一单 | |
| **客单价（AOV）** | GMV ÷ 订单数 | 按"每单"而不是"每人" | 本数据大量批发客户，客单价远高于一般零售，只适合内部横向比较 |
| **客户数** | 有客户编号的去重客户数 | 不含无编号订单 | |
| **复购率** | 时间段内下单 ≥ 2 次的客户 ÷ 下单 ≥ 1 次的客户 | 时间段跟随筛选条件 | 筛选的时间越长，复购率天然越高，**只能同长度时间段之间比较** |
| **同期群留存（第 N 月）** | 首单在 M 月的客户中，在 M+N 月又下过单的比例 | 首单月按客户全部历史中最早一单计 | 能区分"新客留不住"和"老客流失" |
| **新客 90 天复购率** | 首单后 90 天内再次下单的新客 ÷ 新客 | 只看首单在 2010-01-01 至 2011-08-31 的客户，保证每人都有完整 90 天观察期 | 给运营一个可行动的时间窗口 |
| **国家 / 品类贡献** | 该国家（品类）GMV ÷ 总 GMV | 同一筛选条件 | |
| **同比** | 本期 ÷ 去年同期 − 1 | 只在有完整去年同期数据时显示 | |
| **环比** | 本期 ÷ 上一个等长时间段 − 1 | 如选 3 个月，则和前 3 个月比 | |

## 4. 品类怎么来的

原数据**没有品类字段**，只有英文商品名。看板按商品名关键词归成 8 个品类 + "其他"，规则写在 [`scripts/build_data.py`](../scripts/build_data.py) 的 `CATEGORY_RULES` 里，**先匹配先得**（例如 "CHRISTMAS LIGHTS" 归入节日派对而不是灯饰）。

- "其他"占 GMV 约 9.8%，说明规则覆盖了约九成销售额；
- 这是近似分类，用来看结构和趋势够用，不适合精确到单个品类的财务核算。

## 5. 已知的数据限制

1. **2011-12 只有 9 天**，不完整月放进来会让趋势末端断崖、同比失真，所以排除；
2. **2009-12 是数据起点**，这个月的"新客"里混有之前就存在的老客，同期群第一行偏高，看板上做了标注；
3. **约 13% 的 GMV 来自无客户编号的订单**，复购、同期群只基于有编号的订单；
4. 退货不能对应到原订单，月度退货率受个别大额退单影响很大（见发现 3）；
5. 这是一家公司两年的公开数据，结论用于展示分析方法，不代表行业水平。

## 6. 同一个"销售额"，口径不同差多少

以近 12 个月（2010-12 至 2011-11）为例，由 `scripts/analysis.py` 计算：

| 口径 | 金额（£） | 和上一步相比 |
|---|---:|---|
| 原始非退货行直接加总 | 10,444,620 | — |
| 去掉完全重复行 | 9,982,196 | −462,424 |
| 去掉邮费、手续费等非商品行 = **GMV** | 9,632,333 | −349,863 |
| 扣掉退货 = **净销售额** | 9,330,523 | −301,810 |

最宽和最窄的口径相差 **10.7%**。如果两个部门各用一个口径报"销售额"，数字对不上是必然的。这也是先写这份文档、再做看板的原因。
